# Asterium

Asterium — infrastructure partner of the HUMO Token ecosystem.

**Products:**
- **HUMO Token** — USD-backed stable token ($0.0001), issued by HUMO CRYPTO
- **AUZ (Aurum)** — gold-backed token, 1 AUZ = 0.0001 g of physical gold (999.9)
- **Asterium Wallet** — manage HUMO Token, AUZ and other assets
- **HUMO PAY** — processing center: acceptance, conversion, instant settlements
- **Asterium Exchange** — trade HUMO Token and AUZ

**Network:** Solana (Token-2022)

**Websites:**
- HUMO Token: https://humotoken-uzb.github.io/humo/
- AUZ: https://humotoken-uzb.github.io/auz/
